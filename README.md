# My Finance Tracker v1.0 - AI Orchestrated

Offline-first personal finance app built with Google AI Studio + Gemini API.

### Features (from your screenshots):
- Dashboard: Real-time balance ₹40, Income/Expense tracking, Monthly Budget ₹2500 progress
- Transactions: Search by note/category/method, Filters All/Income/Expense
- Budget: Category-wise budgets, Spent vs Limit
- Analytics: 6-month Income vs Expense chart, Category-wise distribution
- Data Management: CSV Export/Import, Load Sample Data, INR Support

### Tech Stack:
Kotlin, Gemini API, Android Studio, LocalStorage, Chart Logic
